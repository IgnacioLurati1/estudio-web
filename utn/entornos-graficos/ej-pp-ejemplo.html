    validar.js. Recorre los campos de texto y, si uno está vacío, avisa, lo enfoca y devuelve false, que frena el envío. Corre ante el evento de envío, con el atributo onsubmit del formulario.

    function validar() {
  var campos = ["nombre", "email", "comentario"];
  for (var i = 0; i < campos.length; i++) {
    var campo = document.getElementById(campos[i]);
    if (campo.value.trim() == "") {
      alert("Completá el campo " + campo.placeholder + ".");
      campo.focus();
      return false;
    }
  }
  return true;
}

    3. Para qué se usa el código

    Es una hoja de estilo interna, porque va dentro de <style>. La primera regla pone en blanco el texto de las listas ul que están dentro del div con id posterior. La segunda pinta de azul los enlaces a que tienen el atributo href y están dentro de esas listas. div#posterior ul es un selector descendiente y a[href], un selector de atributo.

    4. En una línea

    a) Los URIs se componen normalmente de tres partes, el esquema de nombres del mecanismo para acceder al recurso, el nombre de la máquina que aloja el recurso y el nombre del recurso, dado como una ruta.

    b) Las hojas de estilo separan el contenido de la presentación. Si el estilo está en una hoja aparte, cambiarlo en un lugar lo cambia en todas las páginas.

    c) Un elemento desaprobado quedó anticuado por estructuras nuevas y puede declararse obsoleto en el futuro, pero los agentes de usuario deberían seguir dándole soporte. Uno obsoleto no tiene garantía de soporte, porque dejó de estar definido en la especificación.

    d) El selector de id se escribe con # seguido del id, como #nombre, y corresponde a un único elemento del documento.

    e) El selector de atributo toma los elementos que tienen ese atributo, como a[href], que toma los enlaces con href.
