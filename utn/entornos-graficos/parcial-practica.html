    HTML de base

    Estructura del documento

    Un documento tiene la declaración de tipo, una cabecera head y un cuerpo body (Conceptos y Teoría de HTML, páginas 31 y 56).

    <!DOCTYPE HTML>
<html>
<head>
<title>Título de la página</title>
<meta charset="UTF-8">
</head>
<body>
</body>
</html>

    Un elemento tiene apertura, contenido y cierre. Los atributos van en la apertura con espacio, = y comillas. Los elementos vacíos, como img, no tienen cierre. El anidado tiene que ser correcto (páginas 25 a 30).

    <p>Mi gato es <strong>muy</strong> gruñon.</p>

    CSS

    CSS separa el contenido de la presentación. Si el estilo está en una hoja aparte, cambiarlo en un lugar lo cambia en todas las páginas (Material de CSS, páginas 2 y 6).

    Tres formas de aplicar estilos

    FormaDónde vaEjemplo
    ExternaEn un archivo .css, enlazado desde head<LINK rel="stylesheet" href="bach.css" type="text/css">
    InternaEn <style> dentro de head<style> h1 {color: red;} </style>
    En líneaEn el atributo style de la marca<h1 style="color:#FFFFFF">

    Las tres se piden juntas en el parcial de 18/09/2024, y dos de ellas en el ejemplo de parcial.

    Anatomía de una regla

    h1 {color: red;}

    Una regla tiene un selector y una declaración. La declaración es una propiedad con un valor. El selector es el enlace entre el documento y el estilo (Material de CSS, página 4). Varias declaraciones entre llaves forman un bloque (Contenido adicional de CSS, página 5).

    Se agrupan selectores con coma: h1, h2, h3 { color: red; }. Los comentarios van con /* */ (Material de CSS, páginas 9 y 12).

    Otras reglas de sintaxis del mismo apunte.

    • Las declaraciones se separan con punto y coma, y la última también lo lleva (páginas 9 y 16).
    • Si una propiedad lleva varios valores, van separados por espacios. Si admite valores alternativos, van separados por comas, como font-family: Georgia, "Times New Roman", Times, serif; (página 9).
    • Un valor de más de una palabra va entre comillas, como p {font-family: "sans serif";} (página 10).
    • Un error habitual es escribir los caracteres < y > en la hoja de estilo (página 10).
    • No se aconseja repetir selectores, porque dispersa la información (página 11).
    • Las reglas-arroba empiezan con @. @charset, @import y @namespace van al principio de la hoja. @font-face y @media pueden ir en cualquier lugar (página 8).
    • El meta charset va justo después de abrir head, para que el navegador conozca la codificación antes de procesar nada (página 3).

    En cuanto a unidades, el punto, pt, es absoluto y no varía según el entorno. El em es relativo al tamaño de la fuente del elemento, así que margin: 3em es tres veces ese tamaño (página 16).

    Cascada, herencia y especificidad

    Cascada. El formato final de un elemento depende de la combinación de todas las propiedades que lo afectan, también las de los elementos que lo incluyen. Si una propiedad se repite con el mismo peso, gana la última (Material de CSS, páginas 10 y 11).

    Herencia. Un p hereda de body (Material de CSS, páginas 14 a 16). Si body tiene color negro y h1 tiene su propio color rojo, la regla de h1 reemplaza el valor heredado. Conviene fijar juntos el color del texto y el del fondo (página 15).

    Especificidad. Es cómo decide el navegador qué valor se aplica (Contenido adicional de CSS, páginas 20 y 21).

    Qué esPeso
    !important1,0,0,0,0
    Estilo en línea0,1,0,0,0
    #id0,0,1,0,0
    .class y pseudo-clase0,0,0,1,0
    Etiqueta y pseudo-elemento0,0,0,0,1

    En el ejemplo del apunte, h1 vale 1, #content h1 vale 101 y un estilo en línea vale 1000. El apunte dice que !important es mala práctica (página 22).

    Bootstrap

    Bootstrap arma filas de hasta 12 columnas. Una fila es row, va dentro de un container y sus columnas son col-xl-*. Las columnas de una fila suman 12. Con xl, colapsan debajo de 1200 píxeles (Introducción de Bootstrap, páginas 8 y 13).

    PHP

    Tipos

    boolean, integer, float, string, array, object, resource y NULL. gettype dice el tipo, e is_int pregunta si es entero (Introducción teórica de PHP, páginas 2 y 15).

    Son cuatro escalares, dos compuestos y dos especiales. resource guarda una referencia a un recurso externo, como un archivo o una imagen (página 2).

    Una constante guarda un valor que no cambia durante el script. Se define con define o, desde PHP 5.3.0, con const (páginas 3 y 4).

    <?php
define ("saluda", "Buenas tardes.");
echo saluda;
const CONSTANT = 'Hola Mundo';
?>

    Hay operadores unarios, como ! y ++, binarios, como +, y uno ternario, ?:. El ejemplo del apunte es $a == 1 ? $a++ :$a*3; (página 5).

    Funciones y parámetros

    Una función agrupa código para ejecutarlo varias veces, o con distintos parámetros. return devuelve el valor al lugar desde donde se la llamó (Introducción teórica de PHP, página 6).

    <?php
function prueba($arg1, $arg2) {
echo "Argumento 1 vale: $arg1<br>";
echo "Argumento 2 vale: $arg2<br>";
if ($arg1 < $arg2){
return true;
}
else {
return false;
}
}
$valor_devuelto = prueba(5,10);
?>

    Es el ejemplo de las páginas 6 y 7. La sintaxis general, con los parámetros que hagan falta, es function foo ($arg_1, $arg_2, ..., $arg_n) (página 9).

    El parámetro va por valor si no se indica otra cosa. Un & lo pasa por referencia, y entonces el cambio afecta a la variable original (páginas 10 a 12).

    <?
function porreferencia(&$cadena)
{
$cadena = 'Si cambia';
}
$str = 'Esto es una cadena';
porreferencia ($str);
echo $str; // Imprime 'Si cambia'
?>

    Un parámetro con valor por defecto se escribe con =, y el valor es una constante. Los que tienen valor por defecto van a la derecha de los que no tienen (páginas 13 y 14).

    La base aparece en 3 de 4 prácticas de 2023 y 2024. El modelo completo está en Confección de bases de datos, de 2019.

    Una base de datos relacional almacena mucha información y la ofrece rápido, combinando y ordenando los datos. Se organiza en tablas, con filas o registros. Para acceder hace falta un gestor, como MySQL. SQL, Structured Query Language, es el estándar para insertar, actualizar, eliminar y recuperar datos (Teoría de manejo de bases de datos, páginas 2 a 5).

    Fuente: páginas 6 a 9. Salvo en las fechas, hay que indicar el tamaño del campo. En los números se indica si tienen signo. UNSIGNED tiene el doble de rango positivo que SIGNED (página 9).

    Conectarse

    <?php
$link = mysqli_connect("localhost", "root") or die ("Problemas de conexión a la base de datos");
mysqli_select_db($link, "docentes");
?>

    Es conexion.inc del apunte, página 1. Cada página lo incluye con include.

    La sintaxis general es $nombreConexion = mysqli_connect($hostname, $nombreUsuario, $contraseña);. El servidor sale de la cuenta de hosting, y el usuario es el de la base, que puede ser root si no se creó otro (Teoría de manejo de bases de datos, páginas 10 y 11).

    mysql o mysqli

    El material mezcla las dos familias. mysql_connect es para versiones anteriores a PHP 5 y las soluciones viejas la usan. Además el orden de los parámetros cambia. mysqli_select_db($link, "base") y mysqli_query($link, $consulta) llevan la conexión primero. mysql_select_db("base", $link) la lleva al final (Teoría de manejo de bases de datos, páginas 10 a 14).

    Funciones

    Salen de Teoría de manejo de bases de datos, páginas 10 a 33.

    FunciónQué hace
    mysqli_connectDevuelve la conexión o FALSE
    mysqli_select_dbElige la base
    mysqli_queryEjecuta. En INSERT, UPDATE y DELETE da TRUE o FALSE. En SELECT da un resultado

    LIMIT acota las filas, con inicio y cantidad: select * from libros limit 0,4; (páginas 31 a 33).

    limit 5,4 trae 4 registros desde el 5. Con un solo argumento, como limit 8, trae los primeros 8 (página 33).

    Para ir a una fila concreta del resultado está mysqli_data_seek($result, numeroDeFila), que cuenta desde 0. Después mysqli_fetch_array($result) trae esa fila, y cada columna se lee por nombre, como $extraido['ciudad'], o por número, como $extraido[0] (páginas 21 a 24). Los nombres de campo de mysqli_fetch_assoc distinguen mayúsculas y minúsculas (página 25).

    Sesiones

    Una sesión es un conjunto de variables guardadas en el servidor, una por cada visitante (Teoría de Sesiones, página 2). Se usa para mantener datos durante toda la visita.

    Aparece en 3 de 4 prácticas de 2023 y 2024.

    session_start() inicia o continúa la sesión. Hay que llamarla antes de escribir cualquier texto en la página (Teoría adicional de PHP, páginas 17 y 18). $_SESSION es un array asociativo.

    <?php session_start();
if (!isset($_SESSION["contador"])){
$_SESSION["contador"] = 1;
}else{
$_SESSION["contador"]++;
}
?>

    El ejemplo cuenta las páginas visitadas (Teoría adicional, página 19). session_destroy termina la sesión (páginas 23 y 24).

    Al llamar a session_start(), PHP recibe el identificador de sesión que viene en la cookie o en la URL, y si no hay ninguno lo crea (página 17). session_destroy() borra la información de la sesión actual, pero no las variables globales asociadas ni la cookie de sesión. Para desconectar del todo al usuario también hay que destruir el id y borrar esa cookie (páginas 23 y 24).

    ob_start

    Si no se quiere que session_start() sea la primera línea, ob_start guarda la salida en un búfer y ob_end_flush la envía después. Así se elige cuándo mandar el resultado al navegador (Teoría de Sesiones, páginas 15 y 16).

    Para guardar contraseñas el apunte usa md5, una función hash de un solo sentido. Se guarda la contraseña encriptada y, al ingresar, se compara el md5 de lo tecleado con lo guardado. El apunte aclara que no es 100 % seguro, porque la contraseña viaja del cliente al servidor antes de encriptarse (Teoría de Sesiones, páginas 13 a 15).

    Cookies

    Una cookie es una pequeña información de texto guardada en el navegador del visitante (Teoría de Cookies, página 3).

    setcookie("persona",$nombre,time()+86400*365);

    Dura un año, con 86400 segundos por día (página 7). Se lee con $_COOKIE["persona"].

    Solo el nombre es obligatorio. Los otros parámetros son valor, caducidad, ruta, dominio, seguro y solo http (página 11). Qué es cada uno está en la teoría de cookies.

    setcookie("migalleta", "mivalor");
setcookie("cookie2", "mivalor2", time() + 3600);
$_COOKIE["migalleta"];

    Son los ejemplos de la página 12. $_COOKIE es un array asociativo con todas las cookies disponibles para el dominio y el directorio de la página.

    Antes de cualquier texto

    setcookie y session_start van antes de escribir texto en la página. Con una cookie, si no, PHP puede dar «headers already sent» (Teoría de Cookies, página 12).
