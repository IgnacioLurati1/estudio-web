    3. Validar, guardar, controlar repetidos, sesión y cookie

    conexion.inc, como en el apunte, con una base de nombre inventado.

    <?php
$link = mysqli_connect("localhost", "root") or die ("Problemas de conexión a la base de datos");
mysqli_select_db($link, "parcial");
?>

    guardar.php hace todo antes de escribir texto, porque session_start() y setcookie tienen que ir antes. Los errores se juntan en un array y se muestran al final. El control de repetidos cuenta primero y después inserta, como Alta.php del apunte.

    <?php
session_start();
include("conexion.inc");
$vMeses = array("Enero", "Febrero", "Marzo", "Abril", "Mayo", "Junio", "Julio", "Agosto", "Septiembre", "Octubre", "Noviembre", "Diciembre");
$vErrores = array();

// Que se hayan enviado todos los campos y que ninguno llegue vacío
$vCampos = array("nombre", "email", "producto", "mes", "cantidad", "terminos");
foreach ($vCampos as $vCampo) {
  if (!isset($_POST[$vCampo]) || trim($_POST[$vCampo]) == "") {
    $vErrores[] = "Falta completar el campo $vCampo.";
  }
}

// Que tengan el formato correcto
if (count($vErrores) == 0) {
  $vNombre = trim($_POST['nombre']);
  $vEmail = trim($_POST['email']);
  $vProducto = trim($_POST['producto']);
  $vMes = $_POST['mes'];
  $vCantidad = $_POST['cantidad'];
  if (!filter_var($vEmail, FILTER_VALIDATE_EMAIL)) {
    $vErrores[] = "El email no tiene un formato válido.";
  }
  if (!in_array($vMes, $vMeses)) {
    $vErrores[] = "El mes no es válido.";
  }
  if (!ctype_digit($vCantidad) || $vCantidad < 1) {
    $vErrores[] = "La cantidad tiene que ser un número entero mayor que cero.";
  }
}

// Que no exista otro registro con el mismo email, mes y cantidad
if (count($vErrores) == 0) {
  $vSql = "SELECT Count(email) as canti FROM pedidos WHERE email='$vEmail' AND mes='$vMes' AND cantidad='$vCantidad'";
  $vResultado = mysqli_query($link, $vSql) or die (mysqli_error($link));
  $vCantPedidos = mysqli_fetch_assoc($vResultado);
  mysqli_free_result($vResultado);
  if ($vCantPedidos['canti'] != 0) {
    $vErrores[] = "Ya existe un registro con el mismo email, mes y cantidad.";
  }
}

// Guardar en la base, en la sesión y en la cookie
if (count($vErrores) == 0) {
  $vFechaHora = date("Y-m-d H:i:s");
  $vSql = "INSERT INTO pedidos (nombre, email, producto, mes, cantidad, fecha_hora)
  values ('$vNombre', '$vEmail', '$vProducto', '$vMes', '$vCantidad', '$vFechaHora')";
  mysqli_query($link, $vSql) or die (mysqli_error($link));
  $_SESSION["envios"][$vFechaHora] = array("nombre" => $vNombre, "email" => $vEmail, "producto" => $vProducto, "mes" => $vMes, "cantidad" => $vCantidad);
  setcookie("ultimo_registro", $vFechaHora, time()+86400*365);
}
mysqli_close($link);
?>
<!DOCTYPE HTML>
<html>
<head>
<title>Pedido</title>
<meta charset="UTF-8">
</head>
<body>
<?php
if (count($vErrores) > 0) {
  foreach ($vErrores as $vError) {
    echo "<p>$vError</p>";
  }
} else {
  echo "<p>Pedido guardado el $vFechaHora.</p>";
}
?>
</body>
</html>

    La sesión guarda cada envío con su fecha y hora como clave, así que los anteriores no se pierden. La cookie dura un año y se lee después con $_COOKIE["ultimo_registro"].

    Se armó con Parcial de práctica, secciones Tres formas de aplicar estilos, Pseudo-clases de enlaces, Formularios, Validar en el navegador, Recibir un formulario, Base de datos con mysqli (conexion.inc y Alta.php de Confección de bases de datos), Sesiones y Cookies.

    Quedó en duda: Los apuntes no traen una validación completa del lado del servidor. Para el formato se usaron filter_var con FILTER_VALIDATE_EMAIL, ctype_digit, in_array y trim, que no están en el material. is_int, que sí está, da falso con todo lo que llega de un formulario, porque llega como texto. La hoja no dice qué campos tiene la tabla. Se supuso pedidos (nombre, email, producto, mes, cantidad, fecha_hora). «Alineado hacia la derecha» se resolvió con text-align: right; también puede leerse como float: right, que usa la Práctica de CSS. Las consultas pegan los datos en el texto del SQL, como Alta.php del apunte. Colores y tamaños de la salida son aproximados. El PHP no se pudo correr en esta máquina; el HTML y el CSS se probaron en Chromium.
