Cómo se conecta

Lo único que muestra cómo se juntan los bloques es la hoja de 2017. En un mismo examen mezcla un Schema de Mongoose, tests unitarios, un formulario en HTML, conceptos de Angular y una función en JavaScript. Mirá el detalle en Parcial de 2017.

LEER.pdf nombra además «el proyecto», sin decir de qué se trata. Tampoco aclara si el proyecto se evalúa ni qué tecnologías usa.

Qué se evalúa y cómo

Del material solo sale esto.

  • Hay una carpeta llamada Parcial, con un examen de 2017.
  • Esa hoja tiene cinco ejercicios y sus puntajes suman 10.
  • No hay nada sobre finales, regularidad, promoción ni condiciones para aprobar.

Esto hay que preguntárselo a la cátedra.

  1. Cuál es el programa vigente.
  2. Cuántos parciales hay y qué entra en cada uno.
  3. Si hay proyecto, qué tecnologías usa, en particular qué versión de Angular.
  4. Cómo se aprueba y si hay final.

Por dónde arrancar

  1. Conseguí el programa de tu comisión. Es lo que más falta en el Drive.
  2. Si arrancás de cero, seguí el orden de LEER.pdf con las clases grabadas. Si tu proyecto usa Angular, LEER.pdf sugiere priorizar un curso actual de YouTube.
  3. Usá la hoja de 2017 para medirte cuando ya hayas visto los temas. Tomala como una muestra vieja de cómo se preguntó.

Lo que no está acá

En el Drive hay una carpeta llamada «2017-11-08 Resolución (sin corregir e incompleta)». No la usamos. El propio nombre avisa que no está corregida, y nada indica que sea oficial. Tampoco contestamos los ejercicios por nuestra cuenta. Sin un apunte de la cátedra que lo respalde, una respuesta nuestra podría contradecir lo que te van a pedir.

Ejercicio 2. Tests unitarios

Elegir fechas de prueba para una funciónParcial 08/11/2017 Plan viejo

«Indique que fechas utilizaría para asegurar que los test unitarios aseguren el correcto funcionamiento de la siguiente función para el cálculo de edad. Sugerencia, primero piense en los tests que crearía sin analizar el código y luego revisando el código evalúe si requiere tests adicionales».

function getAge(dateString) {
    var today = new Date();
    var birthDate = new Date(dateString);
    var age = today.getFullYear() - birthDate.getFullYear();
    var m = today.getMonth() - birthDate.getMonth();
    if (m < 0 || (m === 0 && today.getDate() < birthDate.getDate())) {
    age--;
    }
    return age;
}

La sugerencia de la consigna te marca dos pasadas. En la primera pensás los tests sin mirar el código. En la segunda leés el código y decidís si hacen falta más.

Ejercicio 3. Formulario en HTML

Escribir el HTML de un formulario de ingresoParcial 08/11/2017 Plan viejo

«Escribir el html del siguiente formulario de ingreso de la figura».

La figura es la pantalla «Sign in to GitHub». Trae estos elementos:

  • El campo «Username or email address».
  • El campo «Password», con el enlace «Forgot password?» en el mismo renglón.
  • El botón «Sign in».
  • Abajo, en un recuadro aparte, «New to GitHub? Create an account.»

Ejercicio 4. Preguntas teóricas

Cuatro preguntas sobre Angular, responsive y JavaScriptParcial 08/11/2017 Plan viejo
  1. «Defina algunos de los elementos de Angular como framework: Componente, Servicio, Template. ¿Qué otro elemento conoce?»
  2. «Explique con sus palabras responsive web.»
  3. «¿Qué significa y para que sirve @Input() y @Output() en Angular 4?»
  4. «¿Qué diferencia hay entre let y var en la definición de variables?»
