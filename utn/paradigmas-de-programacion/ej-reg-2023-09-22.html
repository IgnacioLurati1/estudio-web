    Enunciado

    Preguntas con opciones

    Salen de este examen, algunas adaptadas. Dejalas para el final, porque las opciones pueden dar pistas.

    1. 1

      ¿A qué concepto hace referencia lo siguiente: «Oculta la representación de los datos internos de un objeto»?

      Se tomó: Parcial para regularizar 22/09/2023, pregunta 3

      El objeto dice qué puede hacer, pero no cómo lo hace.

    2. 2

      ¿A quién se le envía el mensaje que invoca un método de clase?

      Se tomó: Parcial para regularizar 22/09/2023, pregunta 1, adaptada

      Los métodos de clase se invocan enviando el mensaje a la clase, no a una instancia.

    3. 3

      ¿Cuál es la diferencia entre mensaje y método?

      Se tomó: Parcial para regularizar 22/09/2023, pregunta 4, adaptada

      Un mensaje tiene receptor, selector y, en general, argumentos. El método es el código ejecutable.
