    Hoja de repaso

    Tecnologías de Desarrollo de Software IDE. Lo central de cada instancia, según el material de la cátedra.

    Plataforma

    SiglaEn una línea
    CLRMotor de ejecución. Memoria (Garbage Collector), seguridad, excepciones, hilos
    BCLTipos predefinidos, organizados en namespaces
    MSIL / CILCódigo intermedio que genera el compilador
    JITPasa MSIL a nativo en tiempo de ejecución
    CTSCómo se declaran y administran los tipos
    CLSReglas comunes de los lenguajes. Subconjunto del CTS
    CLIEspecificación: CTS + metadatos + CLS
    Ensamblado.exe o .dll con IL, tipos, recursos y manifiesto

    Por valor: contiene el dato, en la pila. Por referencia: guarda la dirección, en el Heap. Todos derivan de System.Object.

    Solución .sln (se comparte) y .suo (del usuario). Un proyecto que usa otro necesita referencia y using.

    Intellisense, refactorización y snippets son del IDE (Visual Studio). El CLR es el motor que ejecuta.

    C# y objetos

    • Cortocircuito: A || B no evalúa B si A es True. A && B no evalúa B si A es False.
    • enum: arranca en 0, tipo int por defecto, conversión explícita.
    • try / catch (del específico al general) / finally (siempre) / throw.
    • Acceso: public, protected, internal, protected internal, private.
    • Pilares: abstracción, encapsulamiento, herencia, polimorfismo.
    • Abstracta: no se instancia, implementación parcial. Interfaz: contrato, no se instancia, prefijo I.
    • virtual permite sobrescribir. override sobrescribe. new oculta.
    • : base(...) llama al constructor de la clase base. static: sin instancia.
    • partial: una clase en varios archivos (formulario y diseñador).
    • List<T>: tipo fijo, error al compilar, sin cast.
    • LINQ: var, inicializadores, tipos anónimos, lambda, métodos de extensión, query expressions.

    Windows Forms

    • Show() no modal, ShowDialog() modal. Application.Run(new Form1()) arranca.
    • InitializeComponent: código generado que crea los controles.
    • Control por código: declarar, instanciar, configurar, agregar a la colección de controles.
    • Cierre: FormClosing se puede cancelar, FormClosed ya cerró.
    • Anchor ancla a bordes, Dock fija a un borde. TableLayoutPanel tabla, FlowLayoutPanel flujo.
    • ClickOnce: actualizaciones automáticas con mínima interacción. Sirve para cualquier aplicación Windows Form o de consola.

    ADO.NET

    ObjetoClave
    ConnectionOpen, Close, ConnectionString
    CommandExecuteReader, ExecuteScalar, ExecuteNonQuery, ExecuteXMLReader
    DataReaderSolo avance, solo lectura, conectado
    DataAdapter.Fill y .Update entre DataTable y origen
    DataSetEn memoria, colección de DataTable, desconoce el origen
    DataSet tipadoHereda de DataSet, comprueba tipos al compilar

    Entity Framework

    • ORM, Code First. Se opera sobre entidades. Soporta LINQ.
    • ORM es Object Relational Mapping. Los datos del dominio se manejan como clases y objetos.
    • DbContext con un DbSet<T> por tabla. SaveChanges graba.
    • Estados: Detached, Unchanged, Added, Deleted, Modified.
    • Mapeo: Data Annotations (Key, Required, NotMapped) o Fluent API.
    • Herencia: TPH (por defecto, una tabla con discriminador), TPT, TPC.
    • Crear la base: EnsureCreated o Migrations.

    Blazor

    Server: corre en el servidor, SignalR, necesita conexión. WebAssembly: corre en el navegador, carga inicial más larga. Componentes, páginas con @page, binding one-way y two-way. Archivos iniciales: Program.cs, App.razor, MainLayout.razor.

    API REST

    VerboHaceCódigo
    GETTodos, o uno por id200, 404 si no existe
    POSTCrea201
    PUTActualiza204, 404 si no existe
    DELETEElimina204, 404 si no existe
    • 400 Bad Request, 401 Unauthorized, 403 Forbidden, 500 Internal Server Error.
    • Swagger: AddEndpointsApiExplorer, AddSwaggerGen, UseSwagger, UseSwaggerUI.
    • Controlador: [ApiController], [Route("api/[controller]")], ControllerBase.

    Asincronía

    • Task y Task<T> modelan la operación. async habilita await.
    • await solo dentro de un método asincrónico. Cede el control hasta que termina la tarea.
    • Sufijo Async. async void solo para manejadores de eventos.
    • I/O-bound (red, base, archivos): await directo. CPU-bound: Task.Run.

    Capas

    Presentación, Negocio y Datos. La presentación instancia a Negocio y Negocio a Datos. La interfaz nunca habla con Datos. Los cambios quedan contenidos en una o pocas capas. A cambio, se pierde algo de performance.

    Antes de entregar una práctica en PC

    • Prefijo en solución, proyectos y namespaces, como pide tu enunciado.
    • Compila y ejecuta sin errores. Es el primer criterio de evaluación.
    • En aprobación directa: todos los servicios asíncronos, se prueban con Swagger, la base con el nombre pedido, el estado inicial lo pone el servicio.
    • Zip con el nombre pedido, si el enunciado lo exige.
