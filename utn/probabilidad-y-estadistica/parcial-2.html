    Variable aleatoria discreta

    Variable aleatoria y variable discreta

    Las experiencias aleatorias dan como resultado sucesos elementales. Una variable aleatoria se define al asignar un valor numérico a cada suceso elemental de una experiencia aleatoria.

    Una variable es discreta cuando el conjunto de valores posibles que puede asumir (llamado rango o recorrido de la variable: RxR_xRx​) es un conjunto finito o infinito numerable.

    Apunte V.A.D., pág. 2

    En criollo

    Una variable aleatoria le pone un número a cada resultado posible. Tirás dos monedas y contás las caras. Ese conteo es la variable. El azar decide el resultado, y el número sale de ahí.

    La distribución de probabilidad le asigna una probabilidad a cada valor posible. Se lee como una frecuencia relativa, pero de una población, a veces conceptual: «los infinitos días» en las mismas condiciones (V.A.D., pág. 2 y 3).

    Distribución de probabilidad y función acumulada

    Una distribución de probabilidad es una función que enumera todos los valores posibles que puede asumir una variable aleatoria, junto con sus probabilidades.

    La distribución de probabilidad describe al comportamiento de la variable en una población. Esto significa que las probabilidades se pueden interpretar igual que las frecuencias relativas pero en vez de referirse a una muestra, se refieren a una población.

    Propiedades, con pi=P(X=i)p_i=P(X=i)pi​=P(X=i):

    pi≥0, ∀ip_i\geq 0,\ \forall ipi​≥0, ∀i

    ∑i∈Rxpi=1\sum_{i\in R_x}p_i=1∑i∈Rx​​pi​=1 (condición de cierre)

    Binomial

    Tirás muchas veces una misma experiencia con dos resultados y contás cuántas veces salió uno. Para que sea Binomial, tienen que cumplirse tres cosas.

    Distribución binomial

    Esta distribución surge de un tipo de experiencia aleatoria en la que ocurre uno de dos resultados posibles: A o Aˉ\bar AAˉ, la cual es llamada experiencia de Bernoulli.

    Si se consideran n repeticiones independientes de la experiencia en las cuales P(A) es constante, y se define la variable X: nº de veces que ocurre el resultado A en las n repeticiones, entonces X tiene distribución binomial.

    Por lo tanto, para afirmar que una variable tenga distribución binomial se necesita lo siguiente:

    1.- Existen n repeticiones que conducen a uno de dos resultados: éxito o fracaso (A y Aˉ\bar AAˉ), es decir, n ensayos de Bernoulli.

    2.- La probabilidad de éxito P(A) en cada ensayo de Bernoulli, la cual se denomina π, permanece constante de repetición en repetición.

    3.- Los ensayos de Bernoulli son independientes.

    La última condición significa que el resultado de un ensayo no influye en la probabilidad de éxito en otro ensayo.

    P(X=k)=(nk)πk(1−π)n−k,para k entero entre 0 y nP(X=k)=\binom{n}{k}\pi^k(1-\pi)^{n-k},\quad\text{para k entero entre 0 y n}P(X=k)=(kn​)πk(1−π)n−k,para k entero entre 0 y n

    Apunte V.A.D., pág. 7 y 8

    Demostración

    Generalizando, se puede obtener la probabilidad de X = k, para n repeticiones de la experiencia y con probabilidad de éxito π. Primero se obtiene la probabilidad de una secuencia con k sucesos A y n−k sucesos Aˉ\bar AAˉ. Esta probabilidad es πk(1−π)n−k\pi^k(1-\pi)^{n-k}πk(1−π)n−k. Luego se obtiene la cantidad de secuencias de n sucesos donde k de ellos son A y n−k son Aˉ\bar AAˉ, y se multiplican ambos resultados.

    Hipergeométrica

    Cuando elegís de un lote finito sin devolver, cada elección cambia lo que queda. Por eso deja de ser Binomial.

    Distribución hipergeométrica

    Poisson

    Sirve para contar eventos a lo largo de un tiempo o una longitud, como caídas de un sistema.

    Distribución de Poisson

    Una variable aleatoria X tiene una distribución de Poisson con parámetro λ > 0 y notamos X∼Po(λ) cuando:

    P(X=K)=λke−λk!k:0,1,2,…,n,…P(X=K)=\frac{\lambda^k e^{-\lambda}}{k!}\qquad k:0,1,2,\ldots,n,\ldotsP(X=K)=k!λke−λ​k:0,1,2,…,n,…

    Exponencial

    Mide el tiempo hasta que pasa algo: hasta que se cae un sistema, entre cortes de energía.
