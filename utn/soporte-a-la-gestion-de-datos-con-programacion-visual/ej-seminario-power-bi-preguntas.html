    Enunciado

    Preguntas - Power BI ¿Qué significan las siglas ‘ETC’? Enfoque, Transparencia y Carga Extracción, Transformación y Confidencialidad Enfoque, Transparencia y Confidencialidad Extracción, Transformación y Carga

    Indicar cuál o cuáles de las siguientes afirmaciones son CORRECTAS acerca de la Business Intelligence (BI). Es un tipo de software que se alimenta de datos de negocios. Es una herramienta de análisis de datos que presenta reportes, paneles, tablas y gráficos de forma amigable para el usuario para facilitar la toma de decisiones. Las herramientas de BI permiten a los usuarios de negocio acceder a diferentes tipos de datos como históricos, de terceros, semi-estructurados, etc. Todas son correctas.

    Indique cuál o cuáles de las siguientes opciones NO representa una funcionalidad principal de Power BI. Toma de decisiones organizacionales inteligentes. Creación de informes Transformación de Datos Ninguna es correcta . ¿Qué son las ‘Tooltips’ en Power BI? Son herramientas que le permiten seleccionar ciertas categorías o rangos de datos para ver en las visualizaciones. Son una herramienta práctica para obtener información adicional y contextual sobre los datos presentados en las visualizaciones. Son elementos que puede clicar para realizar acciones específicas, como cambiar la granularidad de los datos o acceder a vistas detalladas. Ninguna de las anteriores

    Indique cuál/es de las siguientes afirmaciones respecto al Conjunto de Datos es correcta. Los conjuntos de datos pueden ser una combinación de muchos orígenes diferentes. Power BI solo procesa datos que se encuentren almacenados en Bases de Datos Relacionales. Es posible importar a Power BI un dataset que esté almacenado en un archivo de extensión .xlsx (Excel). Ninguna de las afirmaciones son correctas.

    ¿Qué es el Tablero de Datos en Power BI? Una ventana interactiva que permite una comprensión más profunda de los datos, facilitando tanto su visualización como el análisis. Ventana que lista todos los datos que han sido cargados con una estructura similar a una hoja de cálculo Excel. Pestaña que muestra las diferentes visualizaciones que se le puede agregar al informe, como así también filtros y valores. Ninguna es correcta.

    ¿A qué elemento característico de Power BI se lo define como una colección de visualizaciones que aparecen juntas en una o varias páginas? Paneles Informes Diapositivas Infografías

    ¿Qué indica la granularidad de los datos en contexto de Power BI? No es un concepto que se emplee en este contexto. Refiere a la cantidad de registros (filas de una tabla) que tiene una entidad a la cual se conecta Power BI. Refiere a la cantidad de atributos (columnas de una tabla) que tiene una entidad a la cual se conecta Power BI. Refiere al nivel de detalle presente en un conjunto de datos.

    Indique el/los nivel/es de granularidad que existen (de manera rigurosa). Granularidad Media Granularidad Alta No existen niveles de granularidad. Granularidad Baja.

    En función del siguiente contexto, indicar a qué nivel de granularidad se refiere: “(...) una visualización que muestra el total de matrículas de estudiantes por facultad en un gráfico de barras. Cada barra representa una facultad y su altura corresponde al total de inscripciones. No se detalla información sobre las carreras o programas dentro de cada facultad.” Granularidad Alta. Granularidad Media. Granularidad Baja. No se provee la información suficiente para contestar.
