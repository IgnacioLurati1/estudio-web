    La idea general

    La cátedra la resume así en su presentación: programación en Python, full stack, con patrón de tres capas. Los datos van en SQLite o MySQL. Se usan paquetes como Pandas, frameworks como Django, Flask o Kivy, APIs, GitHub, el ORM SQLAlchemy y PyCharm o VS Code.

    En criollo

    Imaginate un sistema de turnos. Abajo hay una base que guarda los turnos. En el medio, código que decide si un turno se puede dar. Arriba, la pantalla que ve la gente. La materia te enseña a armar esos tres pisos en Python y a hacer que se hablen.

    CapaQué pide la cátedra para el TPI
    DatosUna base (MySQL, Mongo o SQLite), con acceso directo o con un ORM (Alchemy o Django)
    NegocioAl menos una regla de negocio, con un test que la verifique en los métodos de la clase de negocio
    InterfazDe escritorio con Tkinter, web con Flask, Django o Kivy, o una API

    Cómo se conecta

    Cada tema es una pieza del TPI. Python y objetos son la base de todo. sqlite3 y SQLAlchemy arman la capa de datos. Las clases con reglas arman la capa de negocio. Flask arma la presentación.

    El parcial de 2026 junta dos de esas piezas en un programa corto, una página de Flask que lee de una base SQLite. Por eso conviene empezar a estudiar por Flask con SQLite y volver hacia atrás con lo que no entiendas.

    Qué material hay

    • De la cátedra. La presentación de la materia, las diapositivas de introducción a Python y de SQLAlchemy, y las consignas del seminario y del TPI.
    • Libros de la carpeta de bibliografía y de las clases. Python para todos, Python para informáticos, el tutorial de Flask de Tutorials Point, Explore Flask y el capítulo de bases de datos de Foundations for Analytics.
    • De alumnos. Un seminario de Power BI y un TPI de 2023. Sirven para ver la forma de la entrega, no como teoría de la cátedra.
    • No revisado. Los cuadernos de clase (.ipynb) y los .py no entraron en esta guía. Quedan en el Drive, en Teoricas2023. Ahí está casi todo lo de MVC y las lecciones de objetos.

    Libros escritos para Python 2

    Python para todos, Python para informáticos y el tutorial de Flask usan Python 2 en sus ejemplos. La cátedra usa Python 3.8 o 3.9. En esta guía los ejemplos de esos libros van con print(...), la forma de Python 3. Cualquier otro cambio está avisado.
