    Python

    TemaLo que hay que tener
    Importfrom modulo import objeto usa el nombre directo. import modulo pide modulo.nombre. import * es mala práctica
    AlcanceLocal, enclosing, global, built-in (LEGB)
    Números7//2 da 3, 7%2 da 1, ** eleva
    CadenasBase 0, inmutables. c[ini:fin] no incluye fin. c[-1] es el último. find da -1 si no encuentra
    Listas []Mutables. insert, append, remove, del, pop, sort
    Tuplas ()Inmutables. Con un elemento lleva coma: ("x",)
    Diccionarios {}keys(), values(), clave in d.keys(). Claves inmutables
    Vacío0 y '' valen False. or devuelve el primero verdadero
    Funcionesdef f(a, b=1, *otros). Sin return devuelve None
    DecoradorRecibe una función y devuelve otra. Varios corren de abajo hacia arriba
    Excepcionestry, except, else si no hubo error, finally siempre. raise lanza
    __name__Vale "__main__" si ejecutás el archivo y el nombre del módulo si lo importás
    PaqueteDirectorio con __init__.py

    Objetos

    ConceptoQué es
    Clase y objetoLa clase es la plantilla. El objeto agrupa estado (atributos) y funcionalidad (métodos)
    __init__, selfSe ejecuta al crear el objeto. self es el objeto actual y Python lo pasa solo
    Herenciaclass Hija(Padre). Llamar al padre: Padre.metodo(self, args)
    Herencia múltipleSi dos padres tienen el mismo método, gana el de más a la izquierda
    PolimorfismoObjetos de distintas clases responden al mismo mensaje. No hay sobrecarga
    Encapsulación__nombre es privado por name mangling. property tapa getters y setters
    Especiales__new__, __del__, __str__, __len__

    SQLite y SQL

    con = sqlite3.connect('archivo.db')   # o ':memory:'
cur = con.cursor()
cur.execute("INSERT INTO t VALUES (?, ?)", (a, b))
con.commit()                          # sin esto no se guarda
cur.execute("SELECT ...")
filas = cur.fetchall()                # fetchone, fetchmany(n)
con.close()
    SQLForma
    ConsultaSELECT columnas FROM tabla WHERE condicion ORDER BY columna. * es todas las columnas
    AltaINSERT INTO tabla (a, b) VALUES (x, y)
    CambioUPDATE tabla SET a = x WHERE condicion. Sin WHERE, cambia todas
    BajaDELETE FROM tabla WHERE condicion

    ? y una tupla aparte evitan la inyección SQL. En WHERE la igualdad es con un =.

    SQLAlchemy

    Pasos: mapeo, clases, Engine, relacionar con metadatos, Session, usar la sesión.

    Base = declarative_base()
class Persona(Base):
    __tablename__ = 'persona'
    id = Column(Integer, primary_key=True)
engine = create_engine('sqlite:///foo.db')
Base.metadata.create_all(engine)
session.add(obj); session.commit()
session.query(Persona).filter(...).order_by(...).all()

    Patrones: Data mapper, Unit of work, Identity map. relationship con back_populates hace bidireccional. Consultas: all, first, count, filter, order_by, join.
