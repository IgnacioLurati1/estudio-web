    Lo básico de Python

    Salvo aviso, esta sección sale de las diapositivas de la cátedra, introduccion a python2018_a.pptx.

    Python es de código libre, interpretado, sensible a mayúsculas y minúsculas, y dinámicamente tipado. Los comentarios van con #. Los programas tienen extensión .py y se suelen llamar scripts. Los .pyc y .pyo son precompilados: si los encuentra, los usa.

    En PyCharm se crea un proyecto y se le asigna un intérprete. Desde la versión 2017.3 crea solo un entorno virtual por proyecto, aunque se puede elegir uno existente. La guía de instalación indica pip list para comprobar que el intérprete quedó bien.

    Importar

    Se pidió completar líneas de import1° parcial 2026

    La diferencia entre las dos formas es qué nombre queda disponible y cómo se escribe después.

    from math import pi      # se lo puede usar directamente
import math
n = math.sin(0.15)       # hay que indicar la biblioteca
from PyQt4.QtCore import *
x = QString()            # no hace falta decir dónde está definido

    La última forma es «sólo para pruebas, no es una buena práctica», dice la diapositiva. Python para todos (pág. 74) también la llama mala práctica.

    Alcance de los nombres

    Los nombres se buscan en este orden: local, enclosing, global y built-in (LEGB). Enclosing se refiere a que una función puede definirse dentro de otra.

    Tipos y referencias

    Los tipos son dinámicos, se definen al asignar valores. type(...) devuelve la clase del argumento. Las variables son referencias a objetos, y id(objeto) devuelve su identificador. Los números y los strings son inmutables: si cambiás el valor de una variable numérica, pasa a apuntar a otro objeto.

    Números

    int (n = 7) y float, que se define por asignar un valor con punto decimal (n = 7.0). Se convierte con float(entero) o int(decimal).

    %Resto del cociente7%2 da 1

    Cadenas

    Son arrays con índice de base 0. Los valores negativos buscan desde la derecha, empezando en -1. En un slice cadena[ini:fin], el último no está incluido.

    c = "La pelota roja"
c[0], c[5], c[-1]   # ('L', 'l', 'a')
c[:4]               # 'La p'
c[-3:]              # 'oja'
c[4:7]              # 'elo'
c.find("p")         # 3
c.find("q")         # -1, no lo encontró

    Errata del apunte

    La diapositiva «Substrings» define c = "La pelota roja ", con un espacio al final, y dice que c[-3:] da 'oja'. Con ese espacio daría 'ja '. Acá va sin el espacio, como en la diapositiva anterior. Lo probé en Python. Archivo: introduccion a python2018_a.pptx.

    Como son inmutables, no se puede asignar un carácter adentro:

    p = "pad"
p[1] = "o"                      # error
p = p[:1] + "o" + p[2:]         # así sí: 'pod'
p = "o".join((p[:1], p[2:]))    # otra forma, partiendo de "pad": 'pod'

    Secuencias especiales: \n nueva línea, \t tabulado, \\ para insertar una barra, \' y \" para insertar comillas.

    Lógicos

    Cualquier dato vacío equivale a False (0, ''). Hace la evaluación mínima necesaria. En un or, si el primer dato es verdadero, devuelve ese. Si no, devuelve el segundo.

    Listas

    Se escriben con [] y se comportan como los strings al indexar, pero se pueden modificar.

    frutas = ["manzana", "pera", "durazno", "limón"]
frutas[:2]
frutas[-1]
frutas.insert(3, "naranja")   # intercala
del frutas[2]                 # borra
frutas.remove("pera")         # borra
frutas[1] = "uva"             # cambia un elemento

    La hoja de la clase suma append, reverse, sort, index y pop, y las comprensiones de listas: [n ** 2 for n in l] arma una lista nueva con los cuadrados (Python para todos, pág. 61).

    Tuplas

    Se escriben con () y son inmutables. Con 2 elementos o más no necesitan paréntesis.

    vacia = ()
uno = ("canario",)
varios = ("jilguero", 43.5, "otro")
origen = (0, 0, 0)

    Errata del apunte

    La diapositiva «Tuplas» escribe uno = ("canario"). Eso no es una tupla, es un string entre paréntesis. Python para todos (pág. 26) dice que hay que añadir una coma en las tuplas de un solo elemento. Lo puse con la coma.

    Diccionarios

    Se escriben con {} y guardan pares clave-valor. Las claves deben ser inmutables, así que una tupla sirve.

    articulos = {"copa": 200, "vaso": 120, "tenedor": 30}
articulos["vaso"]               # 120
articulos["cuchillo"] = 130     # agrega la pareja
articulos.keys()                # las claves
articulos.values()              # los valores
"vaso" in articulos.keys()      # True
datos3d = {(3, 7, -2): "Verde"}

    Errata del apunte

    La diapositiva escribe dict('A':200, 'B':230, …), que no es Python válido. Con dict se escribe dict(A=200, B=230). Lo probé en Python. Archivo: introduccion a python2018_a.pptx.

    Funciones

    Sale de Python para todos, págs. 36 a 41. Se declaran con def. Declararla no la ejecuta. Solo asocia un nombre al código. Si no indicás un valor de retorno, devuelve None. Una cadena en la primera línea es el docstring.

    def imprimir(texto, veces = 1):       # valor por defecto
    print(veces * texto)

def varios(param1, param2, *otros):   # otros es una tupla con los extra
    for val in otros:
        print(val)

def f(x, y):
    return x * 2, y * 2               # devuelve una sola tupla

a, b = f(1, 2)
imprimir(veces = 2, texto = "hola")   # por nombre, en cualquier orden

    Una lambda es una función anónima en línea, con una sola expresión (pág. 60): lambda n: n % 2.0 == 0.

    Decoradores

    Un decorador es «una función que recibe una función como parámetro y devuelve otra función como resultado» (Python para todos, pág. 63). Se aplica con @ antes de la definición. Si hay varios, se ejecutan de abajo hacia arriba (pág. 64).

    En criollo

    Es un envoltorio. Tenés una función, le ponés algo alrededor y seguís llamándola con el mismo nombre. El @app.route de Flask es uno de estos: envuelve tu función y la anota para una dirección web.

    Excepciones

    Sale de Python para todos, págs. 65 a 68. Son errores detectados durante la ejecución. Si no se capturan, el programa se interrumpe y muestra el traceback.

    try:
    z = x / y
except ZeroDivisionError:
    print("Division por cero")
else:
    print("Solo si no hubo excepción")
finally:
    print("Limpiando")      # se ejecuta siempre

    Un except puede tratar varios tipos con una tupla. Para crear una excepción propia, armás una clase que herede de Exception y la lanzás con raise.

    Módulos y paquetes

    Sale de Python para todos, págs. 72 a 76.

    • Un módulo es un archivo Python. Se importa con su nombre, sin la extensión.
    • import también ejecuta el código del módulo. Por eso un print suelto del módulo se imprime al importarlo.
    • Python busca los módulos en los directorios de PYTHONPATH, que se ven con sys.path. Si no encuentra, lanza ImportError.
    • Un paquete es un directorio con un archivo __init__.py, que suele estar vacío. Se separa con punto: import paquete.modulo.
    print("Se muestra siempre")
if __name__ == "__main__":
    print("Se muestra si no es importacion")

    Al ejecutar el módulo directamente, __name__ vale "__main__". Al importarlo, vale el nombre del módulo.

    Para instalar paquetes se usa pip. El tutorial de Flask (pág. 2) usa pip install virtualenv, virtualenv venv y pip install Flask. Los cuadernos de la clase del 26/04/2023 tratan el tema, pero no entraron en esta guía.

    Orientación a objetos

    Sale del capítulo de Python para todos que la cátedra subió a la clase del 10/05/2023, págs. 42 a 52.

    Clases y objetos

    «Un objeto es una entidad que agrupa un estado y una funcionalidad relacionadas.» El estado va en atributos y la funcionalidad, en métodos. Una clase es «una plantilla genérica a partir de la cuál instanciar los objetos» (págs. 42 y 43).

    class Coche:
    """Abstraccion de los objetos coche."""
    def __init__(self, gasolina):
        self.gasolina = gasolina
        print("Tenemos", gasolina, "litros")

    def arrancar(self):
        if self.gasolina > 0:
            print("Arranca")
        else:
            print("No arranca")

    def conducir(self):
        if self.gasolina > 0:
            self.gasolina -= 1
            print("Quedan", self.gasolina, "litros")
        else:
            print("No se mueve")

mi_coche = Coche(3)
print(mi_coche.gasolina)  # 3
mi_coche.conducir()       # Quedan 2 litros

    __init__ se ejecuta justo después de crear el objeto. self es el primer parámetro de los métodos y se refiere al objeto actual. Python lo pasa solo. Por eso Coche(3) lleva un solo parámetro aunque la definición tenga dos.

    En criollo

    La clase es el molde. Cada objeto es una torta hecha con ese molde. self es «esta torta», así cada una guarda su propia gasolina y no se mezcla con la del vecino.

    Herencia

    La subclase contiene todos los atributos y métodos de la superclase. La clase padre se pone entre paréntesis.

    class Instrumento:
    def __init__(self, precio):
        self.precio = precio

    def tocar(self):
        print("Estamos tocando musica")

class Guitarra(Instrumento):
    pass

    Escribir en la subclase un método con el mismo nombre es sobreescribirlo. Para llamar al del padre: Instrumento.__init__(self, precio), y ahí sí hay que pasar self (pág. 46).

    Python permite herencia múltiple: class Cocodrilo(Terrestre, Acuatico). Si dos padres tienen el mismo método, prevalece el de la clase más a la izquierda. Con ese ejemplo, desplazar imprime «El animal anda» (pág. 47).

    Polimorfismo

    Es «la habilidad de objetos de distintas clases de responder al mismo mensaje» (pág. 47). En Python no existe la sobrecarga de métodos. El último sobreescribe a los anteriores (pág. 48).

    Encapsulación

    Es impedir el acceso a ciertos métodos y atributos desde fuera de la clase. Python no tiene modificadores de acceso, depende del nombre (págs. 48 a 50):

    • Si empieza con dos guiones bajos y no termina con dos, es privado.
    • Si no, es público.
    • Si empieza y termina con dos, es un método especial.

    No es realmente privado. El nombre se renombra (name mangling) y se puede llegar con ej._Ejemplo__privado(). Para un acceso controlado se escriben getters y setters, y property los esconde detrás de un atributo.

    class Fecha(object):
    def __init__(self):
        self.__dia = 1

    def getDia(self):
        return self.__dia

    def setDia(self, dia):
        if dia > 0 and dia < 31:
            self.__dia = dia
        else:
            print("Error")

    dia = property(getDia, setDia)

    __del__(self)Cuando el objeto va a ser borrado

    Bases de datos con sqlite3

    Se tomó en un programa con huecos1° parcial 2026

    La hoja usa connect, cursor, execute, fetchall y close, en ese orden, y pide una consulta SQL.

    Python trae su propio módulo para SQLite. No hace falta un servidor aparte. Es una base liviana en disco (Foundations for Analytics, capítulo 4, págs. 145 y 148). Otros módulos siguen la misma especificación, DB-API, así que el código casi no cambia con otra base (Python para todos, pág. 117).

    El SQL que hace falta

    Sale de Python para informáticos, capítulo 14, págs. 180 y 181. Hay cuatro comandos básicos, además de crear y borrar tablas.

    CREATE TABLE Canciones (titulo TEXT, reproducciones INTEGER)
INSERT INTO Canciones (titulo, reproducciones) VALUES ('My Way', 15)
SELECT * FROM Canciones WHERE titulo = 'My Way'
SELECT titulo, reproducciones FROM Canciones ORDER BY titulo
UPDATE Canciones SET reproducciones = 16 WHERE titulo = 'My Way'
DELETE FROM Canciones WHERE titulo = 'My Way'
    • El * pide todas las columnas. WHERE elige las filas.
    • En SQL la igualdad es con un solo =, a diferencia de Python.
    • Un UPDATE sin WHERE actualiza todas las filas de la tabla.
    • DROP TABLE borra la tabla y todo su contenido, sin opción de deshacer (pág. 178).

    Conexión y cursor

    connect recibe la ruta del archivo, o ':memory:' para usar la RAM (Python para todos, pág. 120). Si el archivo no existe, se crea (Python para informáticos, pág. 177).

    import sqlite3
conn = sqlite3.connect('musica.sqlite3')
cur = conn.cursor()
cur.execute('DROP TABLE IF EXISTS Canciones ')
cur.execute('CREATE TABLE Canciones (titulo TEXT, reproducciones INTEGER)')
conn.close()

    En criollo

    La conexión es abrir la puerta de la base. El cursor es el empleado que entra con tus pedidos. Le das un SQL con execute y después te trae lo que encontró con fetch.

    Traer filas

    Después de un SELECT hay tres métodos del cursor (Python para todos, pág. 122):

    MétodoDevuelve
    fetchone()La siguiente tupla, o None si no hay más
    fetchmany(n)La cantidad de tuplas indicada
    fetchall()Todas las tuplas

    Cada fila es una tupla, y fetchall da la lista de esas tuplas (Foundations, pág. 150). También se puede recorrer el cursor con un for.

    Guardar cambios

    Cada cambio se confirma con commit(). Si no lo llamás, no se guarda (Foundations, pág. 148). rollback() cancela la transacción actual (Python para todos, págs. 121 y 122). Al terminar se cierran el cursor y la conexión (págs. 123 y 124).

    Este ejemplo es de Foundations, págs. 145 y 146, con los datos del libro:

    import sqlite3
con = sqlite3.connect(':memory:')
query = """CREATE TABLE sales
           (customer VARCHAR(20),
            product VARCHAR(40),
            amount FLOAT,
            date DATE);"""
con.execute(query)
con.commit()

data = [('Richard Lucas', 'Notepad', 2.50, '2014-01-02'),
        ('Jenny Kim', 'Binder', 4.15, '2014-01-15'),
        ('Svetlana Crow', 'Printer', 155.75, '2014-02-03'),
        ('Stephen Randolph', 'Computer', 679.40, '2014-02-20')]
statement = "INSERT INTO sales VALUES(?, ?, ?, ?)"
con.executemany(statement, data)
con.commit()

cursor = con.execute("SELECT * FROM sales")
rows = cursor.fetchall()

    executemany corre el SQL una vez por cada tupla. Ahí rows queda como una lista de cuatro tuplas (págs. 149 y 150). El mismo capítulo carga y actualiza filas desde un CSV con el módulo csv (págs. 152 y 157).

    Parámetros e inyección SQL

    No armes el SQL pegando cadenas. Te deja vulnerable a la inyección SQL. Los ? marcan dónde van los valores y se pasan aparte, en una tupla (Python para todos, pág. 123, y Foundations, pág. 149).

    cursor.execute("""select * from sucursales
                  where ciudad=?""", (ciudad,))

    En sqlite3 el estilo es qmark, el del ?. La coma de (ciudad,) es la de una tupla de un solo elemento.

    Errata del apunte

También arma los parámetros de connect en una sola cadena, y connect los recibe por separado (Python para todos, pág. 120). No probé este código contra un MySQL.

    ORM con SQLAlchemy

    Salvo aviso, sale de las diapositivas de la cátedra, introduccion a python2018_sqlAlchemy.pptx. La diapositiva da como actual la versión 1.2.7, así que algunas importaciones pueden diferir en una versión nueva.

    Un ORM (Object Relational Mapper) se usa para manejar las bases de datos como colecciones de objetos y eliminar trabajo repetitivo. Asocia clases de Python con tablas, e instancias de esas clases con filas. Sincroniza los cambios de los objetos con sus filas y permite expresar consultas en términos de las clases.

    En criollo

    Sin ORM escribís SQL y recibís tuplas. Con ORM trabajás con un objeto Persona, le cambiás el nombre y le pedís a la sesión que guarde. El SQL lo arma él.

    Patrones que implementa

    PatrónDefinición de la diapositiva
    Data mapper«La tabla estará envuelta en una clase desde la que se podrá acceder a la información, realizar modificaciones, borrados e inserciones.»
    Unit of work«Mantiene una lista de los objetos afectados por una transacción de negocio y coordina la escritura de los cambios y la resolución de problemas de concurrencia.»
    Identity mapCaché en memoria que evita traer dos veces los mismos datos. «Si los datos solicitados ya se han cargado desde la base de datos, el mapa de identidad devuelve la misma instancia del objeto ya instanciado.»

    Los pasos

    1. Declarar el mapeo de la base de datos, lo que crea los metadatos.
    2. Crear clases para cada entidad.
    3. Crear el Engine para un motor de base de datos.
    4. Relacionar el Engine con los metadatos.
    5. Crear la Session y relacionarla con el Engine.
    6. Usar la sesión para gestionar los datos.

    Ejemplo con tablas relacionadas

    __tablename__ y una columna con primary_key=True son indispensables. Junté en un solo bloque los imports, que en las diapositivas aparecen por separado.

    from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy import Column, ForeignKey, Integer, String, create_engine
from sqlalchemy.orm import relationship, sessionmaker

Base = declarative_base()

class Persona(Base):
    __tablename__ = 'persona'
    id = Column(Integer, primary_key=True)
    nombre = Column(String(250), nullable=False)

class Domicilio(Base):
    __tablename__ = 'domicilio'
    id = Column(Integer, primary_key=True)
    calle = Column(String(250))
    calle_nro = Column(String(250))
    cod_postal = Column(String(250), nullable=False)
    persona_id = Column(Integer, ForeignKey('persona.id'))
    persona = relationship(Persona)

engine = create_engine('sqlite:///sqlalchemy_ejemplo.db')
Base.metadata.create_all(engine)     # equivale a Create Table en SQL

    El Engine

    Es el objeto que actúa como interfaz con la base de datos. Usualmente lo emplea el ORM por dentro. La conexión se intenta recién al recibir una orden concreta (lazy connecting). La sintaxis es dialect+driver://username:password@host:port/database.

    create_engine('mysql+pymysql://root:1234@localhost/soporte')
create_engine('sqlite:///foo.db')                 # ruta relativa
create_engine(r'sqlite:///C:\path\to\foo.db')     # ruta absoluta
create_engine('sqlite://')                        # en memoria

    Flask

    Sale del tutorial de Flask de Tutorials Point, de la bibliografía. Las páginas son las impresas en la hoja. Ese libro es de 2015 y recomienda Python 2.7 (pág. 2). La cátedra usa Python 3.

    Flask es un framework web en Python, basado en el toolkit WSGI Werkzeug y el motor de plantillas Jinja2. Se lo llama micro framework. No trae capa de base de datos ni validación de formularios. Eso se suma con extensiones (pág. 1).

    La aplicación mínima

    Se tomó un programa de Flask1° parcial 2026

    Hay que reconocer las partes de una aplicación de Flask, empezando por sus imports.

    from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello_world():
    return 'Hello World'

if __name__ == '__main__':
    app.run()

    Un objeto de la clase Flask es la aplicación WSGI. Su constructor recibe el nombre del módulo actual. route es un decorador que indica qué URL llama a la función. run arranca el servidor local (pág. 3).

    run(host, port, debug, options) tiene todos los parámetros opcionales. host es 127.0.0.1 por defecto y port, 5000. Con debug=True el servidor se recarga solo y muestra un depurador (págs. 3 y 4).

    Rutas y variables

    Una parte de la URL puede ser variable y llega como parámetro de la función (págs. 6 y 7).

    @app.route('/hello/<name>')
def hello_name(name):
    return 'Hello %s!' % name

@app.route('/blog/<int:postID>')
def show_blog(postID):
    return 'Blog Number %d' % postID

    Los conversores son int, float y path. Con /python/, la dirección /python y /python/ dan lo mismo. Con /flask, pedir /flask/ da 404 (pág. 7). También existe app.add_url_rule para unir una URL con una función (pág. 5).

    Métodos HTTP y request

    Por defecto, una ruta responde a GET. Se cambia con el argumento methods (pág. 10).

    MétodoQué hace, según el tutorial
    GETEnvía datos sin cifrar. Es el más común
    HEADIgual a GET, sin cuerpo de respuesta
    POSTEnvía datos de un formulario HTML al servidor
    PUTReemplaza las representaciones actuales del recurso
    DELETEElimina las representaciones actuales del recurso
    from flask import Flask, redirect, url_for, request
app = Flask(__name__)

@app.route('/success/<name>')
def success(name):
    return 'welcome %s' % name

@app.route('/login', methods=['POST', 'GET'])
def login():
    if request.method == 'POST':
        user = request.form['nm']
        return redirect(url_for('success', name=user))
    else:
        user = request.args.get('nm')
        return redirect(url_for('success', name=user))

    El objeto request hay que importarlo. Sus atributos son form, args (lo que va después del ? en la URL), cookies, files y method (pág. 18).

    Plantillas

    render_template busca el HTML en la carpeta templates, junto al script (pág. 13). Jinja2 usa estos delimitadores (pág. 15):

    DelimitadorPara qué
    {% ... %}Sentencias (if, for)
    {{ ... }}Expresiones que se imprimen
    {# ... #}Comentarios
    @app.route('/hello/<user>')
def hello_name(user):
    return render_template('hello.html', name=user)
    <h1>Hello {{ name }}!</h1>

    Los archivos estáticos, como JavaScript o CSS, van en la carpeta static y se enlazan con url_for('static', filename='hello.js') (pág. 17).

    Redirect y url_for

    url_for arma la URL de una función a partir de su nombre. redirect manda a otra dirección, con código 302 por defecto (págs. 8 y 28).

    Errata del apunte

    En la pág. 8 del tutorial de Flask, la ruta es /user/<name>, pero el texto pide probar /hello/admin. Con ese código, la dirección que corresponde es /user/admin. En la pág. 17 escribe filename=hrllo.js'. Arriba puse 'hello.js', el archivo que nombra el texto.

    Cookies y sesiones

    La cookie se guarda en la computadora del cliente, como archivo de texto. Se escribe sobre la respuesta y se lee de request.cookies (págs. 22 y 23).

    resp = make_response(render_template('readcookie.html'))
resp.set_cookie('userID', user)
name = request.cookies.get('userID')

    La sesión guarda datos del lado del servidor, entre que el cliente entra y sale. Se usa como un diccionario, session['username'], y necesita app.secret_key definida (págs. 25 y 26).

    Flask con SQLite

    Se tomó esta combinación1° parcial 2026

    Una función de Flask que abre la base, ejecuta una consulta, trae todas las filas y las devuelve.

    Este es el ejemplo completo del tutorial para listar registros (págs. 52 y 53).

    from flask import Flask, render_template, request
import sqlite3 as sql
app = Flask(__name__)

@app.route('/list')
def list():
    con = sql.connect("database.db")
    con.row_factory = sql.Row
    cur = con.cursor()
    cur.execute("select * from students")
    rows = cur.fetchall()
    return render_template("list.html", rows=rows)

if __name__ == '__main__':
    app.run(debug=True)

    Para insertar, usa with sql.connect("database.db") as con, un INSERT con ?, y commit. Si algo falla, hace rollback dentro de un except (pág. 52).

    Flask con SQLAlchemy
