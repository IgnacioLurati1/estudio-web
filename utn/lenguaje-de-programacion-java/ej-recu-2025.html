    Cada clase va en su archivo, con el mismo nombre. El diagrama pide getters y setters en todas. Acá van solo los que usa el cálculo, y los demás los genera Eclipse con Source › Generate Getters and Setters.

    La hoja pide getCostoMensual «para los empleados», y las reglas hablan del costo de cada dispositivo. Por eso hay dos. El de cada dispositivo aplica las reglas, y el de Empleado suma los de sus dispositivos.

    Relación del diagramaDónde quedó
    Empleado 1..1 a 0..* DispositivoUna ArrayList<Dispositivo> en Empleado
    SmartPhone 0..* a 1..1 PlanUn atributo Plan en SmartPhone
    Notebook 0..* a 1..1 SeguroUn atributo Seguro en Notebook
    import java.util.ArrayList;

public class Empleado {

    private int id;
    private String nombre;
    private String apellido;
    private ArrayList<Dispositivo> dispositivos = new ArrayList<Dispositivo>();

    public Empleado(int id, String nombre, String apellido) {
        this.id = id;
        this.nombre = nombre;
        this.apellido = apellido;
    }

    public void agregarDispositivo(Dispositivo dispositivo) {
        dispositivos.add(dispositivo);
    }

    public float getCostoMensual() {
        float total = 0;
        for (Dispositivo d : dispositivos) {
            total += d.getCostoMensual();
        }
        return total;
    }
}

    Dispositivo es <<abstract>> en el diagrama, así que no se puede crear con new. Su getCostoMensual() devuelve el costo base, que «aplica para todos».

    public abstract class Dispositivo {

    private int nroSerie;
    private String marca;
    private String modelo;
    private float costoBase;

    public Dispositivo(int nroSerie, String marca, String modelo, float costoBase) {
        this.nroSerie = nroSerie;
        this.marca = marca;
        this.modelo = modelo;
        this.costoBase = costoBase;
    }

    public float getCostoMensual() {
        return costoBase;
    }

    public float getCostoBase() {
        return costoBase;
    }
}

    Notebook y SmartPhone redefinen getCostoMensual(). Arrancan con super.getCostoMensual(), que es el costo base, y le suman lo suyo. Empleado llama al método de cada dispositivo sin saber de qué tipo es, y se ejecuta el de la clase del objeto. Ahí están la herencia, la redefinición y el polimorfismo.

    public class Notebook extends Dispositivo {

    private float peso;
    private Seguro seguro;

    public Notebook(int nroSerie, String marca, String modelo, float costoBase, float peso, Seguro seguro) {
        super(nroSerie, marca, modelo, costoBase);
        this.peso = peso;
        this.seguro = seguro;
    }

    @Override
    public float getCostoMensual() {
        return super.getCostoMensual() + seguro.getImporteMensual();
    }
}

    En el celular, cada consumo se multiplica por su costo del plan.

    costo=costoBase+minutosTotales⋅costoMinuto+smsTotales⋅costoSms+mbTotales⋅costoMb\text{costo} = \text{costoBase} + \text{minutosTotales} \cdot \text{costoMinuto} + \text{smsTotales} \cdot \text{costoSms} + \text{mbTotales} \cdot \text{costoMb}costo=costoBase+minutosTotales⋅costoMinuto+smsTotales⋅costoSms+mbTotales⋅costoMb

    public class SmartPhone extends Dispositivo {

    private int nroTelefono;
    private float minutosTotales;
    private int smsTotales;
    private float mbTotales;
    private Plan plan;

    public SmartPhone(int nroSerie, String marca, String modelo, float costoBase,
            int nroTelefono, float minutosTotales, int smsTotales, float mbTotales, Plan plan) {
        super(nroSerie, marca, modelo, costoBase);
        this.nroTelefono = nroTelefono;
        this.minutosTotales = minutosTotales;
        this.smsTotales = smsTotales;
        this.mbTotales = mbTotales;
        this.plan = plan;
    }

    @Override
    public float getCostoMensual() {
        float costoMinutos = minutosTotales * plan.getCostoMinuto();
        float costoSms = smsTotales * plan.getCostoSms();
        float costoMb = mbTotales * plan.getCostoMb();
        return super.getCostoMensual() + costoMinutos + costoSms + costoMb;
    }
}

    La hoja da la firma y no dice en qué clase va. Acá está en una clase Ejercicio2. «Más letras que el número» es estricto, así que con tamanio igual a 4, «Lucía», de 5 letras, cuenta y «Ana» no.

    import java.util.ArrayList;

public class Ejercicio2 {

    public int cantLargas(ArrayList<String> listaNombres, int tamanio) {
        int cantidad = 0;
        for (String nombre : listaNombres) {
            if (nombre.length() > tamanio) {
                cantidad++;
            }
        }
        return cantidad;
    }
}
