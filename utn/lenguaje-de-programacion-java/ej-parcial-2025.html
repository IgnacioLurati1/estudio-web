    Cada clase va en su archivo, con el mismo nombre. El diagrama pide getters y setters en todas. Acá van solo los que usa el cálculo, y los demás los genera Eclipse con Source › Generate Getters and Setters.

    sueldo=sueldoBasico+adicional del rol\text{sueldo} = \text{sueldoBasico} + \text{adicional del rol}sueldo=sueldoBasico+adicional del rol

    Empleado es abstracta. getSueldo() es igual para todos y llama a getAdicionalRol(), que es abstracto. Cada rol lo redefine con su regla, y al pedir el sueldo se ejecuta el adicional de la clase del objeto. Ahí están la herencia, la redefinición y el polimorfismo.

    public abstract class Empleado {

    private int id;
    private String nombre;
    private String apellido;
    private double sueldoBasico;

    public Empleado(int id, String nombre, String apellido, double sueldoBasico) {
        this.id = id;
        this.nombre = nombre;
        this.apellido = apellido;
        this.sueldoBasico = sueldoBasico;
    }

    public double getSueldo() {
        return sueldoBasico + getAdicionalRol();
    }

    public abstract double getAdicionalRol();
}

    El chofer cobra «la suma de los km de todos los viajes multiplicado por el adicional».

    import java.util.ArrayList;

public class Chofer extends Empleado {

    private double adicionalKm;
    private ArrayList<Viaje> viajes = new ArrayList<Viaje>();

    public Chofer(int id, String nombre, String apellido, double sueldoBasico, double adicionalKm) {
        super(id, nombre, apellido, sueldoBasico);
        this.adicionalKm = adicionalKm;
    }

    public void agregarViaje(Viaje viaje) {
        viajes.add(viaje);
    }

    @Override
    public double getAdicionalRol() {
        double totalKm = 0;
        for (Viaje v : viajes) {
            totalKm += v.getKm();
        }
        return totalKm * adicionalKm;
    }
}

    El vendedor cobra premio solo si «supera» el mínimo, así que con el mínimo justo no hay premio. El porcentaje se toma sobre el costo del viaje de cada pasaje.

    import java.util.ArrayList;

public class Vendedor extends Empleado {

    private int cantidadMinimaPremio;
    private double porcentajePremio;
    private ArrayList<Pasaje> pasajes = new ArrayList<Pasaje>();

    public Vendedor(int id, String nombre, String apellido, double sueldoBasico,
            int cantidadMinimaPremio, double porcentajePremio) {
        super(id, nombre, apellido, sueldoBasico);
        this.cantidadMinimaPremio = cantidadMinimaPremio;
        this.porcentajePremio = porcentajePremio;
    }

    public void venderPasaje(Pasaje pasaje) {
        pasajes.add(pasaje);
    }

    @Override
    public double getAdicionalRol() {
        double premio = 0;
        if (pasajes.size() > cantidadMinimaPremio) {
            for (Pasaje p : pasajes) {
                premio += p.getViaje().getCosto() * porcentajePremio / 100;
            }
        }
        return premio;
    }
}

    La fórmula de la hoja, con la suma de adentro en Libro.

    ∑libros(∑pedidos pendientescantidad−stock)\sum_{\text{libros}} \left( \sum_{\text{pedidos pendientes}} \text{cantidad} - \text{stock} \right)libros∑​​pedidos pendientes∑​cantidad−stock​

    LineaPedido es la clase del medio, con la cantidad. Al crearla se suma a la lista de su libro, así el libro recorre sus líneas y mira si el pedido de cada una está pendiente.

    import java.util.LinkedList;

public class Libro {

    private String isbn;
    private String nombre;
    private int stock;
    private LinkedList<LineaPedido> lineas = new LinkedList<LineaPedido>();

    public Libro(String isbn, String nombre, int stock) {
        this.isbn = isbn;
        this.nombre = nombre;
        this.stock = stock;
    }

    public void agregarLinea(LineaPedido linea) {
        lineas.add(linea);
    }

    public int getCantEnPedidosPendientes() {
        int total = 0;
        for (LineaPedido l : lineas) {
            if (l.getPedido().isPendiente()) {
                total += l.getCantidad();
            }
        }
        return total;
    }

    public int getStock() {
        return stock;
    }
}
    public class LineaPedido {

    private int cantidad;
    private Libro libro;
    private Pedido pedido;

    public LineaPedido(int cantidad, Libro libro, Pedido pedido) {
        this.cantidad = cantidad;
        this.libro = libro;
        this.pedido = pedido;
        libro.agregarLinea(this);
    }

    public int getCantidad() {
        return cantidad;
    }

    public Pedido getPedido() {
        return pedido;
    }
}

    getEjemplaresAPedir recibe la lista de libros, así que va en una clase aparte, acá Ejercicio2.

    import java.util.LinkedList;

public class Ejercicio2 {

    public int getEjemplaresAPedir(LinkedList<Libro> libros) {
        int total = 0;
