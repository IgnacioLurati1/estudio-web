    Cada clase va en su archivo, con el mismo nombre (Inmueble.java, ServicioPrestado.java y así). El diagrama pide getters y setters en todas. Acá van solo los que usa el cálculo, y los demás los genera Eclipse con Source › Generate Getters and Setters.

    agregarServicio suma el servicio a la lista y le avisa al servicio a qué inmueble pertenece.

    import java.util.ArrayList;

public class Inmueble {

    private int id;
    private String direccion;
    private Double m2;
    private ArrayList<ServicioPrestado> servicios = new ArrayList<ServicioPrestado>();

    public Inmueble(int id, String direccion, Double m2) {
        this.id = id;
        this.direccion = direccion;
        this.m2 = m2;
    }

    public void agregarServicio(ServicioPrestado servicio) {
        servicios.add(servicio);
        servicio.setInmueble(this);
    }

    public double getGananciaTotal() {
        double sumatoriaValor = 0;
        double sumatoriaCostos = 0;
        for (ServicioPrestado s : servicios) {
            sumatoriaValor += s.getValor();
            sumatoriaCostos += s.getCosto();
        }
        return sumatoriaValor - sumatoriaCostos;
    }

    public Double getM2() {
        return m2;
    }
}

    ServicioPrestado es abstracta. Resuelve lo que es igual para todos los servicios, que es el costo de equipamiento y la suma de los dos costos, y deja abstractos getValor() y getCostoManoDeObra(), que cambian según el tipo. horas es Duration, como pide el diagrama, y getHorasComoNumero() la pasa a horas con decimales para poder multiplicar.

    import java.time.Duration;
import java.time.LocalDate;
import java.util.ArrayList;

public abstract class ServicioPrestado {

    private int id;
    private String nombre;
    private LocalDate fecha;
    private Duration horas;
    private Inmueble inmueble;
    private ArrayList<Equipamiento> equipamientos = new ArrayList<Equipamiento>();

    public ServicioPrestado(int id, String nombre, LocalDate fecha, Duration horas) {
        this.id = id;
        this.nombre = nombre;
        this.fecha = fecha;
        this.horas = horas;
    }

    public void agregarEquipamiento(Equipamiento equipamiento) {
        equipamientos.add(equipamiento);
    }

    public double getHorasComoNumero() {
        return horas.toMinutes() / 60.0;
    }

    public double getCostoEquipamiento() {
        double total = 0;
        for (Equipamiento e : equipamientos) {
            total += e.getCostoFijo();
        }
        return total;
    }

    public double getCosto() {
        return getCostoEquipamiento() + getCostoManoDeObra();
    }

    public abstract double getValor();

    public abstract double getCostoManoDeObra();

    public Inmueble getInmueble() {
        return inmueble;
    }

    public void setInmueble(Inmueble inmueble) {
        this.inmueble = inmueble;
    }
}

    Cada servicio redefine los dos métodos con su regla. Inmueble llama a getValor() y getCosto() sin saber de qué tipo es cada servicio, y se ejecuta el método de la clase del objeto. Ahí están la herencia, la redefinición y el polimorfismo que pide la hoja.

    En fin de obra, el pago por m2 es «a CADA empleado», por eso se multiplica también por la cantidad de empleados.

    import java.time.Duration;
import java.time.LocalDate;
import java.util.ArrayList;

public class FinDeObra extends ServicioPrestado {

    private Double valorM2;
    private Double pagoM2;
    private ArrayList<Empleado> empleados = new ArrayList<Empleado>();

    public FinDeObra(int id, String nombre, LocalDate fecha, Duration horas, Double valorM2, Double pagoM2) {
        super(id, nombre, fecha, horas);
        this.valorM2 = valorM2;
        this.pagoM2 = pagoM2;
    }

    public void agregarEmpleado(Empleado empleado) {
        empleados.add(empleado);
    }

    @Override
    public double getValor() {
        return getInmueble().getM2() * valorM2;
    }

    @Override
    public double getCostoManoDeObra() {
        return pagoM2 * getInmueble().getM2() * empleados.size();
    }
}
    import java.time.Duration;
import java.time.LocalDate;

public class Limpieza extends ServicioPrestado {

    private Double valorHora;
    private Empleado empleado;

    public Limpieza(int id, String nombre, LocalDate fecha, Duration horas, Double valorHora, Empleado empleado) {
        super(id, nombre, fecha, horas);
        this.valorHora = valorHora;
        this.empleado = empleado;
    }

    @Override
    public double getValor() {
        return getHorasComoNumero() * valorHora;
    }

    @Override
    public double getCostoManoDeObra() {
        return empleado.getSueldoHora() * getHorasComoNumero();
    }
}

    Esta es la versión que filtra por fecha, la del punto extra. MedicamentoUtilizado une la atención con el medicamento y guarda la cantidad. Al registrar el uso en la atención, también se lo suma al medicamento, así cada uno conoce sus usos.

    import java.time.LocalDate;
import java.util.ArrayList;

public class Atencion {

    private int id;
    private LocalDate fecha;
    private String detalle;
    private ArrayList<MedicamentoUtilizado> medicamentos = new ArrayList<MedicamentoUtilizado>();

    public Atencion(int id, LocalDate fecha, String detalle) {
        this.id = id;
        this.fecha = fecha;
        this.detalle = detalle;
    }

    public void usarMedicamento(Medicamento medicamento, int cantidad) {
        MedicamentoUtilizado utilizado = new MedicamentoUtilizado(this, medicamento, cantidad);
        medicamentos.add(utilizado);
        medicamento.agregarUtilizado(utilizado);
    }

    public LocalDate getFecha() {
        return fecha;
    }
}
    public class MedicamentoUtilizado {

    private int cantidad;
    private Atencion atencion;
    private Medicamento medicamento;

    public MedicamentoUtilizado(Atencion atencion, Medicamento medicamento, int cantidad) {
        this.atencion = atencion;
        this.medicamento = medicamento;
        this.cantidad = cantidad;
    }

    public int getCantidad() {
        return cantidad;
    }

    public Atencion getAtencion() {
        return atencion;
    }
}

    getConsumo suma las cantidades de las atenciones con fecha entre desde y hasta, las dos incluidas. debeReponerStock lo invoca con las fechas de hace 1 mes hasta hoy, como pide la hoja.

    import java.time.LocalDate;
import java.util.ArrayList;

public class Medicamento {

    private int id;
    private String nombre;
    private String detalle;
    private int stock;
    private int puntoDePedido;
    private String presentacion;
    private ArrayList<MedicamentoUtilizado> utilizados = new ArrayList<MedicamentoUtilizado>();

    public Medicamento(int id, String nombre, String detalle, int stock, int puntoDePedido, String presentacion) {
        this.id = id;
        this.nombre = nombre;
        this.detalle = detalle;
        this.stock = stock;
        this.puntoDePedido = puntoDePedido;
        this.presentacion = presentacion;
    }

    public void agregarUtilizado(MedicamentoUtilizado utilizado) {
        utilizados.add(utilizado);
    }

    public int getConsumo(LocalDate desde, LocalDate hasta) {
        int total = 0;
        for (MedicamentoUtilizado u : utilizados) {
            LocalDate fecha = u.getAtencion().getFecha();
            if (!fecha.isBefore(desde) && !fecha.isAfter(hasta)) {
                total += u.getCantidad();
            }
        }
        return total;
    }

    public boolean debeReponerStock() {
        LocalDate hoy = LocalDate.now();
        return getConsumo(hoy.minusMonths(1), hoy) > puntoDePedido;
    }
}

    Sin filtrar por fecha, la versión de 4 puntos, getConsumo() no recibe parámetros y suma todas las cantidades, sin el if.
